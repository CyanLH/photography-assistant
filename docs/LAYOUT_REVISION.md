# Layout revision · 2026-10-12

## 요구사항
1. 지도 제공자를 Google Maps JavaScript API로 단일화한다.
2. 메인 콘텐츠가 모바일/데스크톱 화면에서 우선적으로 보이도록 하며 지도는 최대 가용 높이를 사용한다.

## 모바일 가용 영역
지도 상단에 짧은 제목만 남기고 상세 기준점·화각 정보는 지도 아래로 보냈다. 지도 자체가 첫 화면을 대부분 차지한다. 현장 가이드에서는 위쪽 공간을 줄여 지도 대신 나침반과 추천 첫머리가 노출되도록 했다. safe-area 포함 하단 4탭 네비게이션은 기존 행동을 유지한다.

## 디바이스 QA
360×800, 390×844, 768×1024, 1440×1080 CSS px에서 레이아웃 수평 overflow 검증. 실제 키 없는 화면은 SVG fallback이고, Mock 지도 분기는 별도 확인. 운영에서는 Google Maps 로고/저작권 표기, 키 제한, 타일 청구, 모바일 실제 센서 검증이 필요하다.

## v3
각 화면의 제목은 현장 가이드/빛 지도/시간 계획/내 장비로 정리하고 장식적인 설명과 로고를 제거했다. 모바일 헤더는 Photography Assistant 텍스트명만 두며 상태는 본문 위치 표시줄에서 확인한다. 달 위상/천문 시간대/24h 차트를 실제 선택한 좌표로 계산한다.
